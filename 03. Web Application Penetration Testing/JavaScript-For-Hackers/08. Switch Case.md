
8. Switch Case Statement in JavaScript

Definition:
A control-flow statement used to perform different actions based on different conditions (an alternative to complex `if ... else if` chains).

Syntax:
switch (expression) {
    case value1:
        // Code to execute if expression === value1
        break;
    case value2:
        // Code to execute if expression === value2
        break;
    default:
        // Code to execute if no cases match
}

Key Rules:
- Comparison Method: Uses Strict Equality (`===`) to compare the expression with case values (both value and type must match).
- Break Statement: Stops the execution inside the switch block. If omitted, execution "falls through" to the next case regardless of whether it matches.
- Default Case: Executed when no matching `case` is found (Optional).

---

### (JS Core Concept)

جملة **Switch Case** بتستخدم للتعامل مع الشروط المتعددة المعتمدة على متغير واحد بدل ما تكتب سلسلة طويلة جداً من `if ... else if`.

- **طريقة العمل:** الجافاسكريبت بتاخد القيمة اللي بين القوسين `switch(x)` وتقارنها بكل `case` بالترتيب.
    
- **المقارنة الصارمة (`===`):** الـ `switch` بياخد باله من نوع البيانات، يعني `switch(1)` مش هيطابق `case "1":`.
    
- **أهمية الـ `break`:** كلمة `break` بتخرج المتصفح برة جملة الـ `switch` فور تحقق الشرط.
    
- **ظاهرة الـ Fallthrough:** لو نسيت تضع `break` بعد الـ `case` المحققة، المتصفح هينفذ كود الـ `case` اللي بعدها على طول تلقائياً حتى لو شرطها مش متحقق!
    
- **الـ `default`:** الكود الراجع الافتراضي لو مفيش أي `case` طابقت القيمة.
    

### 3. 💻 مثال برمجي تقليدي (Standard Example)

JavaScript

```
function getUserRoleMessage(role) {
    let message;
    
    switch (role) {
        case "admin":
            message = "Full system access granted.";
            break;
        case "editor":
            message = "Content editing access granted.";
            break;
        case "user":
            message = "Standard user access granted.";
            break;
        default:
            message = "Guest access only.";
    }
    
    return message;
}

console.log(getUserRoleMessage("editor")); // Output: "Content editing access granted."
```

### 4. ⚔️ منظور الهكر (JS for Hackers)

جملة الـ `switch` بتوفر فرص ممتازة للهكر سواء في ثغرات منطق التطبيق (Logic Flaws) أو في مجال التخفي وعكس البرمجيات الخبيثة (Malware Analysis / Deobfuscation):

1. **استغلال ثغرة الـ Fallthrough (Missing `break` Vulnerability):**
    
    - لما المطور ينسى كلمة `break` بالخطأ بين الحالات، المهاجم يقدر يطلب الصلاحية الضعيفة (`guest` مثلاً)، فتقوم الجافاسكريبت بتنفيذ كود الصلاحية اللي تحتها فوراً (`admin`) بدون التأكد من شرطها!
        
    - ده بيمكن المهاجم من عمل **Privilege Escalation** بكل سهولة.
        
2. **الـ Control Flow Flattening (تخفي الأكواد الهجومية بالـ Switch):**
    
    - مطورو الـ Malware وأدوات تشفير الكود (JS Obfuscators) بيستخدموا جملة `switch` جوه `while(true)` حلقة مغلقة لتشتيت الـ Reverse Engineers والـ Static Scanners.
        
    - الكود المتسلسل المستقيم بيتم تقطيعه لـ Cases متفرقة، مع متغير عداد `state = 0` بيتنقل بين الحالات لتصعيب فهم مسار التنفيذ.
        
3. **التحايل بنوع البيانات (Strict Equality Bypass):**
    
    - لأن الـ Switch بتستخدم `===` حصراً، لو المطور استقبل مدخلات من الـ API على شكل Number، والمهاجم نجح يبعتها كـ String عبر JSON Payload (أو العكس)، الكود هيتجاهل الـ `case` المخصصة للحماية ويهرب فوراً للـ `default` branch اللي ممكن يكون فيها سلوك غير آمن.
        

### 5. 🎯 أمثلة هجومية وسيناريوهات استغلال (PoC & Payloads)

#### 📌 السيناريو الأول: تصعيد الصلاحيات بسبب نسيان `break` (Fallthrough Exploit)

تخيل كود فحص الأذونات المكتوب في التطبيق:

JavaScript

```
// كود تطبيق يحتوي على خلل منطقي
function processUserAction(userRole) {
    switch (userRole) {
        case "user":
            console.log("[+] User logged in.");
            // المطور نسي يكتب break هنا!
        case "admin":
            console.log("[!] CRITICAL: Admin control panel unlocked!");
            deleteDatabase(); // دالة خطيرة!
            break;
        default:
            console.log("Guest mode.");
    }
}
```

- **طريقة الاستغلال:** المهاجم مش محتاج صلاحية `admin`. بيبعت `userRole = "user"` عادي جداً:
    
    JavaScript
    
    ```
    processUserAction("user");
    ```
    
    - **النتيجة:** المتصفح هيطابق `case "user"` ولعدم وجود `break` هينزل ينفذ `case "admin"` فوراً ويلغي حماية النظام!
        

#### 📌 السيناريو الثاني: تحليل وتعطيل الأكواد المشفرة بـ Control Flow Flattening

إزاي الهكر أو الـ Malware بيخبي الـ Payload جوه Switch معقدة لمنع كشف الـ WAF:

JavaScript

```
// كود XSS/Malware مشفر ومشتت بـ Switch-Case Dispatcher
let state = 1;
while (state !== 0) {
    switch (state) {
        case 1:
            var a = "al";
            state = 3; // التنقل عبر الحالات بشكل غير متسلسل
            break;
        case 2:
            window[a + "ert"](document.cookie); // تنفيذ الـ Payload
            state = 0; // إنهاء اللوب
            break;
        case 3:
            a += "er";
            state = 2;
            break;
    }
}
```
