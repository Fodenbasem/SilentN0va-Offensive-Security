3. Strings & Character Escaping in JavaScript

Declaring Strings:
- Double Quotes: "hello"
- Single Quotes: 'hello'

Escaping Characters (Using Backslash \):
- To include quotes inside quotes:
  const test = "Hello, I am \"a hacker\" inside strings";
  const name = 'Fady became "white hat hacker"'; // No escaping needed when using mixed quotes

Escape Sequences (from image):
  \'  -> Single Quote
  \"  -> Double Quote
  \\  -> Backslash
  \n  -> New Line
  \t  -> Tab
  \r  -> Carriage Return
  \b  -> Word Boundary / Backspace
  \f  -> Form Feed

String Concatenation:
- Using (+) operator:
  const greeting = "Hello " + "Fady Basem, welcome all!";
- Using (+=) operator:
  let message = "Hello";
  message += " World"; // "Hello World"

Constructing Strings with Variables:
  const name = "silentn0va";
  console.log(name + " welcome for all");
  console.log("My name is " + name);

String Properties & Accessing Characters:
- Length property: "fady basem".length (Note: spelling is 'length', not 'lenght')
- Bracket Notation:
  const myName = "silentn0va";
  console.log(myName[0]);  // "s"
  console.log(myName[1]);  // "i"
  console.log(myName[12]); // Returns `undefined` (Not a hard error)

### (JS Core Concept)

النصوص (**Strings**) هي تسلسل من الحروف والأرقام والرموز.

- **تحديد النصوص:** تقدر تكتب النص بين إقتباس مزدوج `"..."` أو فردي `'...'`.
    
- **رمز التخطي (Backslash `\` Escaping):** لو عايز تكتب اقتباس جوه نص مقتبس بنفس العلامة، بتسقبه بـ `\` عشان المتصفح يفهم إنه حرف عادِي ومش نهاية النص.
    
- **تتابع التخطي (Escape Sequences):** رموز خاصة بتعبر عن تنسيقات نصية زي السطر الجديد (`\n`) أو الـ Tab (`\t`).
    
- **دمج النصوص (Concatenation):** دمج نصين أو أكثر باستخدام `+` أو `+=` أو مع متغيرات أخرى.
    
- **خاصية الطول (`.length`):** بترجع عدد الحروف والعلامات جوه النص.
    
- **علامة الاقواس (`[]` Bracket Notation):** بتسمحلك توصل لحرف معين في النص بالـ Index (العد بيبدأ من `0`). لو طلبت Index أعلى من طول النص (زي `name[12]`) بتطلعلك القيمة `undefined` من غير ما يكسر الكود.
    

### 3. 💻 مثال برمجي تقليدي (Standard Example)

JavaScript

```
// String Escaping & Formatting
const path = "C:\\Users\\fady\\Documents"; // Escaping backslash
const quote = "He said: \"JavaScript is awesome!\"";
const multiLine = "First Line\nSecond Line\t(Indented)";

// Concatenation & Length
const firstName = "Fady";
const fullName = firstName + " Basem";
console.log("Total characters:", fullName.length); // 10

// Bracket Notation
console.log("First letter:", fullName[0]); // "F"
console.log("Out of range:", fullName[99]); // undefined
```

### 4. ⚔️ منظور الهكر (JS for Hackers)

الـ Strings وطريقة التعامل معاها هي حجر الزاوية في معظم ثغرات الـ Web Security:

1. **كسر سياق النص وحقن الثغرات (Context Breaking & XSS):**
    
    - لما التطبيق بياخد إدخال الضحية ويحطه جوه متغير JS نصي: `var user = "USER_INPUT";`
        
    - هدف الهكر هو إغلاق النص عن طريق حقن `"` أو `'` لكسر النص وكتابة أومره الخاصة.
        
    - لو السيرفر بيعمل التغليف التلقائي `\"` لمنع الكسر، الهكر بيدور على ثغرة **Double Escaping**: حقن backslash إضافي `\` يحول الـ Escape بتاع السيرفر لـ `\\"` فتتحرر الـ quote الأخيرة!
        
2. **التجاوز بـ Escape Sequences (`\n`, `\r`, `\uXXXX`):**
    
    - الرموز زي `\n` و `\r` بتستغل في كسر الـ Single-line comments (`//`) المحقونة في الـ XSS Payloads.
        
    - استخدام الـ Unicode Escaping (زي `\u0061\u006c\u0065\u0072\u0074` لكتابة `alert`) لتجاوُز الفلاتر والـ WAFs التي تمنع الكلمات الدلالية صراحةً.
        
3. **استدعاء الدوال بـ Bracket Notation بدل النقطة (`.`):**
    
    - في JS، أي دالة أو طريقة تقدر تستدعيها عبر الـ Bracket Notation كـ String!
        
    - بدل ما تكتب `window.alert(1)` (اللي الـ WAF ممكن يكتشفها)، بتكتب `window["alert"](1)`.
        
4. **تجنب Runtime Errors مع الـ `undefined`:**
    
    - فهم إن طلب Index مش موجود بيطلع `undefined` مش `Error` حاسم جداً للهكر؛ لأن وجود Fatal Error في كود الـ XSS بوقف تنفيذ باقي الـ Payload بالكامل.
        

### 5. 🎯 أمثلة هجومية وسيناريوهات استغلال (PoC & Payloads)

#### 📌 السيناريو الأول: تجاوز حماية الـ Escaping بالـ Backslash Injection

تخيل السيرفر بياخد مدخلاتك وبيفلتر الـ Quotes بتحويلها لـ `\"`:

- **الكود الأصلي:** `var search = "USER_INPUT";`
    
- **مدخلات الهكر:** `\" ; alert(document.cookie); //`
    
- **الكود الناتِج جوه المتصفح:**
    

JavaScript

```
var search = "\\"; alert(document.cookie); //";
```

- **الشرح:** الـ Backslash بتاع الهكر ألغى تأثير الـ Backslash بتاع حماية السيرفر (`\\`)، فبقيت الـ Quote حرة وقُفل بها النص وتم تشغيل الـ XSS بنجاح!
    

#### 📌 السيناريو الثاني: كسر التعليقات بالسطر الجديد `\n` (Comment Breakout)

تخيل مدخلاتك محقونة جوه تعليق:

JavaScript

```
// الكود الأصلي للموقع:
// Welcome back, USER_INPUT

// Payload الهكر بيحتوي على \n (New Line):
// Welcome back, Guest \n alert(1);
```

الـ `\n` ينقل كلمة `alert(1)` لسطر جديد خارج نطاق التعليق فتنفذها المتصفح فوراً.

#### 📌 السيناريو الثالث: التخفي وتجاوز الفلاتر بـ Unicode Escape & Bracket Notation

تجاوز WAF قوي يمنع استدعاء الدالة `eval` أو `document.cookie`:

JavaScript

```
// بدل كتابة: document.cookie
// بنستدعيها عن طريق الـ Bracket Notation والـ Unicode Escaping:

window["\u0065\u0076\u0061\u006c"]('al' + 'ert(1)'); // ينفذ eval('alert
```
