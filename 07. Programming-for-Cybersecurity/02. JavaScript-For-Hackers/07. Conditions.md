7. Booleans & Conditional Logic in JavaScript

Booleans:
- Primitive data type with only two values: `true` or `false`.
- Note: `true` and `false` are boolean keywords, whereas `"true"` and `"false"` are Strings.

Conditional Logic (if / else if / else):
function testCondition(myCondition) {
    if (myCondition) {
        return "It was true";
    }
    return "It was false";
}

Comparison Operators:
- Loose Equality (==): Compares values after type coercion (e.g., 10 == "10" is true).
- Strict Equality (===): Compares both value and type (e.g., 10 === "10" is false).
- Strict Inequality (!==): Checks if values or types are NOT equal.
- Relational Operators: `>`, `<`, `>=`, `<=`

Logical Operators:
- AND (&&): Returns true only if both conditions are true.
- OR (||): Returns true if at least one condition is true.

Chained Conditions (Logic Flow):
if (strokes === 1) {
    return "Hole-in-one!";
} else if (strokes <= par - 2) {
    return "Eagle";
} else {
    return "Go Home!";
}

### (JS Core Concept)

الـ **Booleans** والشرطيات (**Conditions**) هي العقل المدبر لخاط سير البرامج واستجابتها للإدخالات المختلفة.

- **القيم المنطقية (Booleans):** بتأخد إما `true` (صحيح) أو `false` (خاطئ). خذ بالك إن `"true"` بين اقتباسات بتعتبر **String** ومش قيمة منطقية!
    
- **المقارنة الضعيفة مقابل الصارمة:**
    
    - `==` (Loose Equality): بيكافئ القيم حتى لو أنواعها مختلفة عبر تحويلها ضمناً (Type Coercion).
        
    - `===` (Strict Equality): الموصى به دائماً؛ لأنه بيقارن **القيمة والنوع** معاً بدون تحويل.
        
- **المعاملات المنطقية (Logical Operators):**
    
    - `&&` (AND): الشرطين لازم يتحققوا مع بعض.
        
    - `||` (OR): يكفي إن شرط واحد يتحقق.
        
- **الجمل الشرطية (`if / else if / else`):** بتحدد المسار اللي الكود بيمشي فيه بناءً على النتيجة المنطقية للشرط.
    

### 3. 💻 مثال برمجي تقليدي (Standard Example)

JavaScript

```
// Dynamic Comparison Example
function compareValues(a, b) {
    if (a === b) {
        return "Strictly Equal (Value & Type)";
    } else if (a == b) {
        return "Loosely Equal (Value only)";
    } else {
        return "Not Equal";
    }
}

console.log(compareValues(10, "10")); // Output: "Loosely Equal (Value only)"
console.log(compareValues(10, 10));   // Output: "Strictly Equal (Value & Type)"

// Logical Operators
let age = 20;
let hasID = true;

if (age >= 18 && hasID) {
    console.log("Access Allowed");
}
```

### 4. ⚔️ منظور الهكر (JS for Hackers)

الـ Logic Flaws والتحويل الضمني للأنواع في الشرطيات تعتبر من أمتع الثغرات اللي المهاجم بيدور عليها في الـ Client-Side والـ Node.js Backend:

1. **كوارث المقارنة الضعيفة (`==` Loose Equality Flaws):**
    
    - لما التطبيق بيستخدم `==` بدل `===` في المقارنة، الجافاسكريبت بتعمل تحويلات مجنونة (Type Coercion):
        
        - `0 == false` $\rightarrow$ `true`
            
        - `"" == false` $\rightarrow$ `true`
            
        - `[] == false` $\rightarrow$ `true`
            
        - `[0] == false` $\rightarrow$ `true`
            
        - `null == undefined` $\rightarrow$ `true`
            
    - لو السيرفر أو الكود بيتأكد من قيمة توكين أو باسورد بـ `==` وقدرت تبعت `0` أو `[]` عبر JSON، الشرط هيتحقق وتتجاوز الفحص (Authentication Bypass)!
        
2. **خدعة الـ Truthy والـ Falsy Values:**
    
    - في JS، القيم دي بس هي الـ **Falsy** (بتتأول لـ `false` جوه الـ `if`):
        
        `false`, `0`, `""`, `null`, `undefined`, `NaN`.
        
    - **كل ما دون ذلك يعتبر Truthy!** بما في ذلك المصفوفات الفارغة `[]` والأوبجكت الفارغة `{}`!
        
    - لو المطور كاتب `if (userInput)` وعامل حسابه إن لو مفيش مدخلات هتكون القيمة Falsy، ببعث `[]` أو `{}` فالبحر بيرجع `true` وتتكسر أمان الدالة!
        
3. **اختطاف المعاملات المنطقية (Short-Circuit Evaluation Hijacking):**
    
    - الجافاسكريبت بتستخدم الـ `||` لتعيين القيم الافتراضية (Default Values): `let role = input.role || "guest";`.
        
    - لو المهاجم بعث قيمة Truthy غير متوقعة (زي أوبجكت محقون)، المعامل `||` بيرجع القيمة الهجومية فوراً وبيوقف التقييم.
        
4. **الترتيب الخطأ في الجمل الشرطية (Order of Execution Flaws):**
    
    - في سلسلة `if ... else if` المتتابعة، لو أول شرط تحقق، المتصفح ببيسقط بقية الشروط فوراً.
        
    - لو شرط الحماية مكتوب في `else if` متأخرة أو بعد شرط عادي سهل التلاعب بيه، المهاجم بيخلي الكود يدخل الشروط الأولى ويمنع حظر الفحص الأمني.
        

### 5. 🎯 أمثلة هجومية وسيناريوهات استغلال (PoC & Payloads)

#### 📌 السيناريو الأول: تجاوز فحص الصلاحيات بـ Truthy Array (`[]`)

تخيل كود في التطبيق بيتحقق هل التوكين موجود أو الصلاحية موجودة:

JavaScript

```
// كود المطور الضعيف
function verifyAccess(userToken) {
    // المطور فاكر إن لو userToken مفيهاش قيمة هتبقى Falsy
    if (userToken) {
        console.log("Token Present! Granting Access...");
        return true;
    }
    console.log("No Token! Access Denied!");
    return false;
}

// المهاجم مش معاه Token، فبيبعت Array فارغة []
let attackerPayload = []; 

// في JS: Boolean([]) بتطلع true!
verifyAccess(attackerPayload); // النتيجة: Token Present! Granting Access...
```

#### 📌 السيناريو الثاني: كسر منطق المقارنة بـ Loose Equality (`==`)

تخيل كود كشف عن كود تفعيل (Activation Code) أو توكين أمان:

JavaScript

```
function checkAdminPin(inputPin) {
    const adminPin = 0; // البين كود المسجل رقم zero
    
    // استخدام المقارنة الضعيفة ==
    if (inputPin == adminPin) {
        return "Access Granted to Admin!";
    }
    return "Invalid PIN!";
}

// المهاجم بعت String فارغ "" أو Array فارغة []
console.log(checkAdminPin("")); // true (لأن "" == 0)
console.log(checkAdminPin([])); // true (لأن [] == 0)
// النتيجة: Access Granted to Admin!
```

#### 📌 السيناريو الثالث: التلاعب بالقيم الافتراضية بـ Short-Circuit (`||`)

تخيل تطبيق بياخد إعدادات الجلسة من الـ User Input:

JavaScript

```
// كود للتطبيق بياخد صلاحية المستخدم أو بيدي صلاحية عادية افتراضياً
function setUserRole(userInput) {
    // لو userInput.role مش موجود هيدي guest
    let role = userInput.role || "guest";
    
    if (role === "admin") {
        console.log("Admin Privileges Unlocked!");
    }
}

// المهاجم بيحقن JSON Object بيحتوي على القيمة المطلوب تجاوزها
setUserRole({ role: "admin" }); // النتيجة: Admin Privileges Unlocked!
```
