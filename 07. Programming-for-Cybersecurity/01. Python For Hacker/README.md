# 🐍💀 Python Basics for Hackers

أهلاً بيك في كورس **Python Basics for Hackers**! 

الكورس ده متصمم مخصوص لأي حد مهتم بمجال الـ **Cybersecurity**، الـ **Ethical Hacking**، أو الـ **Penetration Testing**، وحابب يتعلم لغة Python من الصفر، بس مش مجرد برمجة عادية، لأ، برمجة موجهة عشان تفهم إزاي تبني أدواتك الخاصة وتعمل Automation لمهامك الأمنية.

---

## 🎯 الهدف من الكورس
- فهم أساسيات Python من البداية (Zero to Intermediate).
- ربط كل مفهوم برمجي باستخدام حقيقي في عالم الـ Hacking.
- التدرج في بناء أدوات أمنية مصغرة (Mini Tools) خطوة بخطوة.
- بناء مشروع نهائي متكامل: **0xSN Security Toolkit**.

---

## 📁 محتويات الكورس (Chapters)
الكورس متقسم لـ 10 ملفات Markdown، كل ملف بيمثل Chapter مستقل، ومبني على اللي قبله:

1. **[01-python-basics.md](01-python-basics.md)**: مقدمة عن الأساسيات (Syntax, Variables, Input/Output).
2. **[02-variables-data-types.md](02-variables-data-types.md)**: التعمق في أنواع البيانات (Strings, Lists, Dictionaries) وإزاي بنخزن معلومات الـ Targets.
3. **[03-conditions-loops.md](03-conditions-loops.md)**: اتخاذ القرارات والتكرار (if, for, while) وفكرتها في الـ Brute-forcing.
4. **[04-functions.md](04-functions.md)**: تنظيم الكود في دوال (Functions) قابلة لإعادة الاستخدام.
5. **[05-data-structures.md](05-data-structures.md)**: الهياكل المعقدة (Nested Data) وتحليل بيانات الـ Scans.
6. **[06-files-errors-modules.md](06-files-errors-modules.md)**: التعامل مع الملفات (Wordlists, Logs)، التعامل مع الأخطاء، واستخدام الـ Modules.
7. **[07-networking-python.md](07-networking-python.md)**: أساسيات الشبكات، بناء Sockets، والتعامل مع الـ Web باستخدام مكتبة `requests`.
8. **[08-security-automation.md](08-security-automation.md)**: الأتمتة (Automation)، تشغيل أوامر النظام، التشفير (Hashing, Base64)، والـ Regex.
9. **[09-mini-security-tools.md](09-mini-security-tools.md)**: تجميع كل اللي فات لبناء 3 أدوات أمنية مصغرة.
10. **[10-hacker-project.md](10-hacker-project.md)**: المشروع النهائي.. تجميع الأدوات في سكريبت واحد بواجهة CLI تفاعلية.

## 🛠️ إزاي تستفيد من الكورس؟
- **اقرأ بالترتيب**: كل Chapter بيبني على اللي قبله. متقفزش لـ Chapter جديد قبل ما تفهم اللي في إيدك.
- **جرب الكود**: متكتفيش بالقراية. انسخ الكود، شغله في بيئة الـ Lab بتاعتك (زي Kali Linux أو أي Localhost)، وعدّل عليه.
- **حل الـ Mini Challenges**: في نهاية كل Chapter هتلاقي تحدي صغير (Mini Challenge). حاول تحله بنفسك قبل ما تكمل.
- **خليك آمن وقانوني (Stay Legal)**: الأمثلة والأدوات هنا للأغراض التعليمية. استخدمها دايماً على أهداف تملكها أو معاك تصريح باختبارها (زي بيئات الـ CTFs).
