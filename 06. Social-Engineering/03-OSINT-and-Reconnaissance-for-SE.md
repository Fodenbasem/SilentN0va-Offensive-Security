# جمع المعلومات للترصد والهندسة الاجتماعية (OSINT & Reconnaissance for Social Engineering)

يقدم هذا الملف مادة عملية شاملة حول كيفية استغلال مصادر المعلومات المفتوحة (OSINT) واستخراج بيانات الهدف، هيكل الشركة، بريد الموظفين، والتقنيات المستعملة قبل إطلاق عملية الهندسة الاجتماعية.

---

## 1. استخراج عناوين البريد الموحدة (Email Harvesting & Pattern Discovery)

تحديد نمط تسمية البريد الإلكتروني للشركة (مثل: `first.last@company.com` أو `flast@company.com`).

### 1.1 استخدام أداة theHarvester
```bash
theHarvester -d targetcompany.com -b google,bing,linkedin,crtsh -l 500
```

### 1.2 استخدام أداة EmailFormat و Hunter.io
مواقع متخصصة في تحليل النمط السائد للإيميلات داخل أي منظمة وتوفير قوائم جاهزة بالموظفين وأقسامهم.

---

## 2. جمع معلومات الموظفين والهيكل التنظيمي عبر LinkedIn

يُعتبر موقع LinkedIn المصدر الأول للهندسة الاجتماعية لبناء الهيكل الإداري وفهم توزيع السلطات داخل المؤسسة المستهدفة.

### 2.1 استخراج الأسماء والأدوار الوظيفية باستغلال Cross-Linked Recon
* **الأدوار المستهدفة في الاستطلاع:**
  * **قسم HR (الموارد البشرية):** يُستغل في إرسال السير الذاتية وتحديثات اللوائح.
  * **قسم IT / Helpdesk:** يُستغل في إرسال طلبات إعادة ضبط كلمة المرور ورسائل الدعم الفني.
  * **قسم Finance / Accounting:** يُستغل في هجمات الاحتيال المالي وطلبات التحويل السريع (CEO Fraud / BEC).

### 2.2 البحث عن التقنيات المستخدمة (Tech Stack Hunting)
من خلال قراءة الإعلانات الوظيفية (Job Descriptions) للمؤسسة على LinkedIn أو مواقع التوظيف:
* لو طلبوا: *"خبرة في إدارة Microsoft 365 و Palo Alto VPN"*.
* **الاستنتاج:** الشركة تعتمد على بوابة Microsoft 365 للدخول، وبالتالي يتم تصميم Landing Page مطابقة لصفحة Microsoft 365.

## 3. خوارزميات البحث المتقدم (Google Dorks for OSINT)

استخدام محركات البحث للوصول لملفات حساسة أو وثائق تحتوي على الهيكل الداخلي والمعلومات الخاصة بالشركة.

```text
# البحث عن مستندات إكسل أو وورد تحتوي على قائمة إيميلات
site:targetcompany.com filetype:xls OR filetype:xlsx OR filetype:csv "email"

# البحث عن ملفات إدارية تحتوي على كلمة سر أو معلومات خاصة
site:targetcompany.com filetype:pdf "confidential" OR "internal use only"

# البحث عن بوابات الدخول والأنظمة الداخلية
site:targetcompany.com inurl:login OR inurl:portal OR inurl:vpn

# البحث عن حسابات ومستودعات كود مسربة على GitHub
site:github.com "targetcompany.com"
```

## 4. استخراج الميتابايانات من الملفات العامة (Metadata Extraction)

تحتوي المستندات المرفوعة على موقع الشركة (PDFs, DOCX) على بيانات مخفية متكاملة تشمل: أسماء المستخدمين، نوع نظام التشغيل، الطابعات المستعملة، والمسارات الداخلية.

### 4.1 استخدام أداة ExifTool
```bash
# فحص الميتاداتا لملف واحد
exiftool annual_report.pdf

# استخراج اسم الكاتب والبرنامج المستخدم في إنشائه
exiftool -Author -Creator -Producer *.pdf
```

### 4.2 أتمتة العملية باستخدام أداة FOCA
أداة FOCA تقوم بسحب جميع الملفات العامة التابعة لدومين محدد، واستخراج الميتاداتا تلقائياً رسم خريطة للشبكة الداخلية والمستخدمين.

---

## 5. استغلال الهندسة الاجتماعية المباشرة عبر الهاتف (Vishing Scenarios)

تجهيز سيناريو الاتصال الصوتي المباشر لاستكمال عملية جمع المعلومات:

* **السيناريو:** الإدعاء بأنك موظف الدعم الفني (Helpdesk) وتقوم بتحديث شهادات الأمان للأنظمة.
* **الهدف:** توجيه الضحية لفتح رابط Phishing أو إملاء رمز المصادقة الثنائية (2FA OTP) تلقائياً أثناء المكالمة.
