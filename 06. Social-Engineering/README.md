# دليل الهندسة الاجتماعية (Social Engineering Essentials)

الهندسة الاجتماعية هي فن استغلال العنصر البشري (العنصر الأضعف في منظومة الأمان) للوصول للبيانات الحساسة أو اختراق الشبكات والأنظمة بدون الحاجة لاستغلال ثغرات برمجية مباشرة.

---

## 🎯 الأهداف العملية

1. **فهم النفسية البشرية (Human Hacking):** استغلال مبادئ الثقة، العجلة (Urgency)، والسلطة الإدارية (Authority).
2. **محاكاة هجمات الحقيقة:** بناء صفحات تسجيل دخول مزيفة (Phishing Pages) وسيرفرات إرسال إيميلات (SMTP Relay).
3. **توعية الموظفين (Security Awareness):** كتابة تقارير تفصيلية لتوضيح الثغرات البشرية داخل المنشأة وكيفية إغلاقها.
