# Google Search Techniques

ابدأ broad ثم exact phrase ثم `site:` ثم pivot من title أو identifier. سجّل كل query والنتيجة المفيدة، وافتح المصدر الأصلي. استخدم `filetype:pdf` لمستندات training العامة، وتجنب كلمات مثل password أو secret. في التحقق قارن Google بمحرك آخر، وميّز indexed date عن publication date. تمرين: اكتب ثلاث queries عن `example.org`، ثم اشرح لماذا كل واحدة أضيق. الحد الأساسي: search ranking ليس source reliability.
