# theHarvester

## What is it?
أداة تجمع public names/emails/hosts من مصادر search.

## Installation

## Basic Usage
شغّل على domain تملكه وبمصادر محدودة.

## Important Options
domain، source، limit، وrate controls.

## Practical Example
inventory fictional domain.

## Cybersecurity Use Case

## Limitations

## Common Mistakes
