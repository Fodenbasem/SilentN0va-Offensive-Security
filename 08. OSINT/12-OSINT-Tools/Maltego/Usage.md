# Maltego Usage

ابدأ nodes قليلة، شغّل transform داخل scope، ثم label كل edge بالمصدر والتاريخ. لا تحوّل co-occurrence إلى ownership. اعمل manual validation لكل edge قبل التقرير. تمرين: graph من domain وASN وcertificate، مع edge “observed” بدل “owns” عند عدم اليقين. Limitation: graph لا يعوّض analyst judgment.
