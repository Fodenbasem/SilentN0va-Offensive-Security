# ExifTool

## What is it?
Metadata reader/writer واسع الصيغ.

## Installation
من [exiftool.org](https://exiftool.org/).

## Basic Usage
`exiftool -a -u -g1 file`.

## Important Options
`-j` JSON، `-csv` reports، `-all=` sanitization.

## Practical Example
اقرأ sample image ثم افحص sanitized copy.

## Cybersecurity Use Case
privacy وforensic triage.

## Limitations
metadata قابلة للتعديل.

## Common Mistakes
الكتابة على الأصل وتسريب GPS.
