# Subfinder

## What is it?
Passive subdomain discovery tool.

## Installation
[Project docs](https://github.com/projectdiscovery/subfinder).

## Basic Usage
`subfinder -d example.org -silent` فقط ضمن scope.

## Important Options
domain، sources، وconfig keys.

## Practical Example
قارن names مع `dig`.

## Cybersecurity Use Case
inventory سريع.

## Limitations
لا يثبت liveness أو ownership.

## Common Mistakes
تسريب API keys وتشغيل على نطاق غير مصرح.

## Lab
