# Censys

## What is it?
منصة internet measurement للـhosts وcertificates.

## Installation
Web/API account وفق [docs](https://docs.censys.com/).

## Basic Usage
ابحث عن certificate أو host في owned scope.

## Important Options
query language وtime filters.

## Practical Example
اربط certificate بـdomain ثم تحقق DNS.

## Cybersecurity Use Case
CT وasset discovery دفاعي.

## Limitations
sampling وtime lag وshared infrastructure.

## Common Mistakes
اعتبار host ownership مؤكدًا.
