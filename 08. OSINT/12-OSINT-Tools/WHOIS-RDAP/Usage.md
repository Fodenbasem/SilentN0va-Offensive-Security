# WHOIS/RDAP Usage

نفّذ lookup، استخرج fields المطلوبة فقط، ثم قارنها بمصدر ICANN أو DNS. RDAP منظم ويسهل parsing، بينما WHOIS text قد يختلف. سجّل وقت UTC وحالة redaction. لا تستخدم contact للتواصل غير المصرح. تمرين: قارن output لـ`example.org` وIP documentation، واكتب claim محدودًا. Common mistake: registrar ليس بالضرورة owner ولا hosting provider.
