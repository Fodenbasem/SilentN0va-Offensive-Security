# DNS Tools

## What is it?
Utilities لقراءة DNS records.

## Installation
`dig` يأتي غالبًا مع DNS utilities؛ Windows يمكنه `nslookup`.

## Basic Usage
`dig A example.org` و`dig MX example.org`.

## Important Options
TYPE، `+short`، وserver محدد عند الحاجة.

## Practical Example
قارن A وCNAME وMX.

## Cybersecurity Use Case
asset inventory وmail security review.

## Limitations
TTL، caching، وrecords متغيرة.

## Common Mistakes
اعتبار lookup ownership.
