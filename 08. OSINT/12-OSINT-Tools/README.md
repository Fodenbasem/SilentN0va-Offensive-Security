# OSINT Tools

الأداة تساعدك تجمع أو ترتب signal؛ لا تستبدل validation. استخدم كل Tool على assets تملكها أو CTF معلن، واحترم API keys وrate limits.

## اختيار سريع
Search للـdiscovery، WHOIS/RDAP للتسجيل، DNS للـresolution، Shodan/Censys للـinternet exposure، VirusTotal للـreputation، Maltego للـgraph، SpiderFoot للـautomation، Amass/Subfinder للـdomain inventory، ExifTool للـmetadata.

## قاعدة تشغيل
Scope -> query -> raw output -> corroboration -> evidence -> cleanup.
