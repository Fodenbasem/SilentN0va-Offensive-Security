# IP Investigation Lab

## Lab Objective
تحليل documentation IP بأمان وبناء finding محدود.

## Scenario
SOC fictional أعطاك `192.0.2.10` من sample log.

## Learning Goals
RDAP، PTR، ASN، geolocation limits، reputation.

## Environment
Documentation range، RDAP، `dig`، notes؛ ممنوع scanning.

## Information Given
IP والـtimestamp فقط.

## Tasks
استعلم RDAP، PTR، ASN، قارِن context، واكتب what it does not prove.

## Hints
Documentation ranges لا تمثل production target.

## Solution
سجّل reserved status وغياب attribution الواقعي؛ confidence في أي ownership finding منخفض.

## Explanation
الهدف تعلم حدود الأدوات.

## What We Learned
IP context وfalse positives.
