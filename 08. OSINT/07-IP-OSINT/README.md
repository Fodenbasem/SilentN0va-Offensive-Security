# IP OSINT

IP address ليه أنواع وسياقات مختلفة؛ لا تعتبر geolocation أو reputation دليلًا على شخص أو نشاط ضار لوحده.

## Path
[Basics](./01-IP-Address-Basics.md) -> [RDAP](./02-WHOIS-and-RDAP.md) -> [ASN](./03-ASN.md) -> [Reverse DNS](./04-Reverse-DNS.md) -> [Geolocation](./05-IP-Geolocation.md) -> [Reputation](./06-IP-Reputation.md) -> [Lab](./07-IP-Investigation.md).

## Safety
حلّل IPs من lab أو owned infrastructure، ولا تعمل port scanning على أنظمة مش بتاعتك.
