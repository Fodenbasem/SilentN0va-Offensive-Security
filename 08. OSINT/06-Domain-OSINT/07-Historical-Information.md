# Historical Information

## يعني إيه؟
Historical sources تحفظ snapshots أو records قديمة مثل Web Archive وDNS history.

## ليه مهم؟
تكشف تغيرات domain وbranding وexposure عبر الزمن.

## بيشتغل إزاي؟
حدد date، قارن snapshots، واحترم robots وTerms. لا تعرض بيانات شخصية قديمة بلا ضرورة.

## مثال بسيط
Snapshot قديم يذكر subdomain لم يعد موجودًا.

## Cybersecurity
timeline لبنية attack surface أو incident.

## Tools
Wayback Machine، CT dates، version history.

## Common Mistakes
معاملة snapshot كحقيقة حالية، أو تجاهل capture context.

## Exercises
قارن نسختين fictional وسجل التغيرات.

## Mini Challenge
ما الذي يثبت تاريخًا فقط وليس ownership؟ snapshot content.

## Summary
التاريخ يشرح التغير، لا يضمن الحاضر.
