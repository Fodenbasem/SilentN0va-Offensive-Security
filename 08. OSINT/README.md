# OSINT Learning Module

أهلًا بيك في Module عملي لتعلّم **Open-Source Intelligence (OSINT)** من الأساسيات لحد التحقيقات المنظمة وكتابة التقارير. الشرح بالعربي المصري، والمصطلحات التقنية بالـ English، وكل الأمثلة آمنة ومبنية على بيانات fictional أو أهداف مسموح بها.

## هتتعلم إيه؟
- تعريف Objective وتحويله لأسئلة قابلة للاختبار.
- Search Operators، Search Pivoting، وValidation.
- People، Username، Email، Domain، IP، Social Media، Image وMetadata OSINT.
- استخدام الأدوات مع فهم حدودها، مش مجرد تشغيلها.
- بناء Evidence Log وReport بدرجات Confidence واضحة.

## المتطلبات
أساسيات Web وDNS وLinux، متصفح حديث، وبيئة تدريب قانونية. مش مطلوب تجمع بيانات شخصية عن أشخاص حقيقيين.

## Methodology
`Define Objective -> Collect Initial Information -> Search -> Pivot -> Correlate -> Validate -> Document Evidence -> Report Findings`

## Labs وCTF
الـ Labs تستخدم `localhost`، نطاقات documentation، شركات fictional، أو CTFs. اقرأ [Practical Labs](./13-Practical-Labs/README.md) قبل أي تمرين.

## Ethics
المعلومة Public مش معناها إن استخدامها مباح بلا حدود. أي Investigation لازم تكون Authorized، بأقل قدر من البيانات، ومن غير Login Bypass أو تعامل مع بيانات مسربة. راجع [OPSEC and Ethics](./01-OSINT-Fundamentals/08-OPSEC-and-Ethics.md).
