# OSINT Report Template

## Executive Summary
اكتب finding والـimpact وconfidence في فقرة.

## Scope
Targets، dates، authorization، exclusions.

## Method
Objective -> Collect -> Search -> Pivot -> Correlate -> Validate.

## Findings
لكل finding: claim، evidence IDs، source، timestamp، confidence، limitation.

## Recommendations
إجراء دفاعي قابل للتنفيذ وowner وdeadline.

## Appendix
Queries، hashes، وraw references redacted.

## Common Mistakes
لغة قطعية، links ناقصة، وخلط observation بالاستنتاج.
