# Source Reliability

## يعني إيه؟
تقييم authority، proximity، freshness، transparency، وcorroboration.

## Model
Official/primary غالبًا أقوى، لكن افحص bias والحداثة. Repost لا يُحسب مصدرًا مستقلًا.

## Example
Official advisory + independent vendor analysis أقوى من نسختين من نفس blog.

## Cybersecurity
يمنع قرارات block أو attribution مبنية على rumor.

## Exercise
قيّم أربع sources بدرجة مع rationale.

## Common Mistakes
ranking = reliability، وغياب citation.

## Summary
Reliability حكم مفسر، لا رقم سحري.
