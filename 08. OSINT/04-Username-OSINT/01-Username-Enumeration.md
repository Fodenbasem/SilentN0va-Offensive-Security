# Username Enumeration

## يعني إيه؟
البحث عن username في مصادر عامة لمعرفة أين يظهر، وليس اختبار وجود حسابات عبر login.

## ليه مهم؟
يساعد brand monitoring وCTF، لكنه قد يصبح privacy-invasive.

## بيشتغل إزاي؟
ابدأ exact search، راجع profile pages العامة، واحترم rate limits وTerms.

## مثال بسيط
`"nile_lantern"` مع project keyword في CTF.

## Cybersecurity
اكتشاف impersonation أو إعادة استخدام اسم مؤسسة.

## Tools
Search engines وmanual review؛ لا automation عدواني.

## Common Mistakes
تجربة login، scraping واسع، واعتبار 404 دليلًا.

## Exercises
أنشئ query آمنة لاسم fictional.

## Mini Challenge
فرق بين “ظهر string” و“الحساب يخص persona”.

## Summary
Enumeration discovery محدود، لا verification للهوية.
