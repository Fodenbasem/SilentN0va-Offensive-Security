# Search Engines

Search engine هو نقطة البداية، مش حكم نهائي. اتعلم تضيق السؤال، تقرأ snippet بحذر، وتعمل pivot للمصدر الأصلي.

## Safety
أي query من نوع `site:` يكون على نطاق تدريب أو نطاق عندك تصريح عليه. ممنوع البحث عن أسرار أو بيانات شخصية مسربة.
