# Search Engine Basics

## يعني إيه؟
Search engine يفهرس صفحات ويعرض نتائج حسب relevance، freshness، language، وموقعك.

## ليه مهم؟
نتائج البحث نقطة discovery، لكنها قد تكون ناقصة أو personalized.

## بيشتغل إزاي؟
ابدأ بكلمات قليلة، اقرأ الصفحة الأصلية، استخرج identifier جديد، ثم نفّذ pivot. سجّل query والنتيجة المفيدة.

## مثال بسيط
`"Nile Lantern Labs" policy` ثم افتح المصدر بدل الاعتماد على snippet.

## Cybersecurity
تبحث عن public docs في نطاق owned، وتراجع robots وTerms.

## Tools
Google، Bing، DuckDuckGo، browser devtools للـURL فقط.

## Common Mistakes
علامة اقتباس زائدة، query طويل، والثقة في أول نتيجة.

## Exercises
اكتب خمس queries تتدرج من broad إلى exact عن `example.org`.

## Mini Challenge
استخرج identifier غير حساس من صفحة ثم صمّم query جديدة به.

## Summary
Search دورة تعلم تكرارية، لا زر إجابة.
