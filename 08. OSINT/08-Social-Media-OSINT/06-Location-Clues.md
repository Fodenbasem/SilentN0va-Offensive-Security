# Location Clues

## يعني إيه؟
Clues بصرية أو نصية تشير لمكان: landmark، sign، weather، أو geotag عام.

## ليه مهم؟
يفيد verification وgeolocation CTF، لكنه حساس وقد يعرض شخصًا للخطر.

## بيشتغل إزاي؟
اجمع clue مستقل، قارن maps وdates، واستخدم region-level language.

## مثال بسيط
صورة fictional فيها sign؛ نطابق spelling مع official map، لا عنوان منزل.

## Cybersecurity
تحقق من event venue أو facility عامة ضمن scope.

## Tools
OpenStreetMap، maps، reverse image search.

## Common Mistakes
استنتاج exact address، تجاهل old imagery، أو نشر location حساسة.

## Exercises
صنف clue قوي/ضعيف.

## Mini Challenge
اكتب finding “consistent with area” مع limitation.

## Summary
Geolocation تحتاج قرائن متعددة وحرصًا عاليًا.
