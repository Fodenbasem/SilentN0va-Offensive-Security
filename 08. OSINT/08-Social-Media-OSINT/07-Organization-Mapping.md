# Organization Mapping

## يعني إيه؟
رسم public relationships بين organization، domains، projects، وofficial accounts.

## ليه مهم؟
يشرح structure وbrand presence دون جمع private data.

## بيشتغل إزاي؟
ابدأ official site، اربط links وregistries، وسمِّ كل edge بمصدر وتاريخ.

## مثال بسيط
Company -> status page -> support domain، مع تحقق DNS وofficial navigation.

## Cybersecurity
asset inventory وthird-party risk.

## Tools
Maltego أو graph notes، RDAP، search.

## Common Mistakes
اعتبار vendor subsidiary، أو تحويل co-mention إلى ownership.

## Exercises
ارسم graph من خمس nodes fictional.

## Mini Challenge
ضع edge label “mentions” بدل “owns” عند غياب دليل.

## Summary
نوع العلاقة مهم بقدر وجودها.
