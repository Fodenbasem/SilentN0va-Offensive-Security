# Public Profiles

## يعني إيه؟
صفحة عامة تعرض role أو organization أو projects.

## ليه مهم؟
تفيد verification مهني محدود وتكشف exposure.

## بيشتغل إزاي؟
سجّل claims as stated، تحقق عبر official source، وراجع last updated.

## مثال بسيط
Profile fictional يذكر speaker في event؛ event organizer يؤكد الظهور.

## Cybersecurity
يخدم awareness لا targeting.

## Tools
Browser، event pages، source log.

## Common Mistakes
نسخ phone/address، الخلط بين self-claim وfact.

## Exercises
أنشئ table stated/verified/unknown.

## Mini Challenge
حدد معلومة يجب redaction لها.

## Summary
احتفظ بما يخدم السؤال فقط.
