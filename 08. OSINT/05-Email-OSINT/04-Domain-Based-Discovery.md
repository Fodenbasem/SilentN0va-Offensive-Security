# Domain-Based Discovery

## يعني إيه؟
استخدام Domain للعثور على public docs وcontacts المعلنة رسميًا.

## ليه مهم؟
يربط email context بorganization بدون استهداف أفراد.

## بيشتغل إزاي؟
ابدأ official domain، search `site:` مع policy أو contact، ثم تحقق من page الحالية.

## مثال بسيط
`site:example.org contact security` يبحث عن قناة disclosure.

## Cybersecurity
يساعد معرفة security contact وpublic attack-surface claims.

## Tools
Search، RDAP، DNS، CT.

## Common Mistakes
استخدام domain lookalike، الثقة في directory غير رسمي، أو scraping.

## Exercises
اعثر على صفحة security policy في نطاق training.

## Mini Challenge
ما أقوى؟ security.txt official أم repost؟ الأول غالبًا، مع مراجعة التاريخ.

## Summary
Domain هو context، وليس إذنًا للتفاعل.
