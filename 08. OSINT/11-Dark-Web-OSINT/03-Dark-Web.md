# Dark Web

## يعني إيه؟
شبكات وخدمات تحتاج software أو routing خاص، وليست جزءًا من Web المعتاد.

## ليه مهم؟
لفهم Threat Intelligence ومخاطر exposure، لا للتصفح الفضولي.

## بيشتغل إزاي؟
ادرس تقارير موثوقة وlegal datasets؛ لا تزور markets أو تتعامل مع illegal content.

## مثال بسيط
تقرير رسمي يصف campaign دون فتح onion service.

## Cybersecurity
defensive monitoring عبر providers مصرحين.

## Tools
Threat reports، sandbox، legal feeds.

## Common Mistakes
تنزيل malware، شراء data، أو نشر links.

## Exercises
حلل تقريرًا رسميًا وحدد evidence والحدود.

## Mini Challenge
صمم escalation process عند ظهور credential exposure.

## Summary
المعرفة الدفاعية تكفي غالبًا دون exposure مباشر.
