# Deep Web

## يعني إيه؟
محتوى غير مفهرس مثل dashboards وdatabases خلف login، وقد يكون مشروعًا وشرعيًا.

## ليه مهم؟
يمنع الخلط بين “غير indexed” و“غير قانوني”.

## بيشتغل إزاي؟
لا تحاول تجاوز login؛ استخدم access المصرح به فقط.

## مثال بسيط
Portal داخلي في organization تملكه.

## Cybersecurity
access governance وmonitoring.

## Tools
Authorized browser، audit logs.

## Common Mistakes
credential sharing وbypass.

## Exercises
صنف أمثلة surface/deep.

## Mini Challenge
اكتب policy تمنع unauthorized access.

## Summary
Deep Web ليس مرادفًا لـDark Web.
