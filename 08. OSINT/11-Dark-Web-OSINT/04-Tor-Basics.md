# Tor Basics

## يعني إيه؟
Tor network تستخدم layered routing لتقليل ربط المصدر بالوجهة، وليس anonymity سحرية.

## ليه مهم؟
يفيد privacy education وفهم threat model.

## بيشتغل إزاي؟
Traffic يمر عبر relays؛ endpoints وbrowser behavior قد تكشف معلومات.

## مثال بسيط
قراءة [Tor Project documentation](https://support.torproject.org/) بدل زيارة خدمات مجهولة.

## Cybersecurity
فهم attacker infrastructure وprivacy controls.

## Tools
Tor Project docs وisolated lab عند الحاجة القانونية.

## Common Mistakes
تحميل ملفات، تسجيل دخول بحساب شخصي، أو ادعاء anonymity كاملة.

## Exercises
ارسم threat model.

## Mini Challenge
حدد metadata التي قد تظل ظاهرة.

## Summary
Tor privacy technology لها limits ومخاطر.
