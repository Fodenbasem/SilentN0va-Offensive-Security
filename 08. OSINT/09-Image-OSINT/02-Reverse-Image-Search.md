# Reverse Image Search

## يعني إيه؟
رفع أو إدخال image للعثور على visually similar أو earlier appearances.

## ليه مهم؟
يكشف reposts وcontext mismatch، لكنه لا يضمن original source.

## بيشتغل إزاي؟
استخدم crop غير حساس، قارن dates وsource quality، واحفظ URLs فقط عند الحاجة.

## مثال بسيط
صورة fictional تظهر في blog قديم قبل claim حديث.

## Cybersecurity
كشف fake brand assets وphishing pages.

## Tools
Google Lens، Bing Visual Search، TinEye وفق Terms.

## Common Mistakes
رفع صور شخصية، اعتبار match exact proof، أو تجاهل edits.

## Exercises
قارن ثلاثة results واكتب limitations.

## Mini Challenge
حدد أي result هو earliest documented appearance، لا “original” قطعيًا.

## Summary
Reverse search أداة pivot لا حكم نهائي.
