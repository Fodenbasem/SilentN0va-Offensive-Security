# Image OSINT Basics

## يعني إيه؟
تحليل image file ومحتواه وسياقه ومصدره.

## ليه مهم؟
يساعد verification وbrand monitoring، لكن الصور قابلة للتعديل وإعادة الاستخدام.

## بيشتغل إزاي؟
احفظ الأصل، احسب hash، اقرأ metadata، ثم visual clues وreverse search.

## مثال بسيط
صورة Wikimedia لها source وlicense وupload date يمكن مقارنتها بادعاء جديد.

## Cybersecurity
تحقق من phishing attachments وincident artifacts في lab.

## Tools
ExifTool، reverse image services، `sha256sum`.

## Common Mistakes
تعديل الأصل، الاعتماد على pixels وحدها، ونشر faces بلا داعٍ.

## Exercises
سجل provenance لصورة تدريبية.

## Mini Challenge
فرق بين “الصورة موجودة قبل الحدث” و“الصورة تثبت الحدث”.

## Summary
Image evidence يحتاج provenance وسياق.
