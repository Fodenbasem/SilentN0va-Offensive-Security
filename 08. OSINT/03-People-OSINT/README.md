# People OSINT

القسم ده يشرح تحليل معلومات Public لشخص fictional أو authorized، مع التركيز على عدم تحويل clues ضعيفة إلى هوية مؤكدة.

## Path
[Basics](./01-People-OSINT-Basics.md) -> [Names](./02-Names-and-Aliases.md) -> [Usernames](./03-Usernames.md) -> [Profiles](./04-Public-Profiles.md) -> [Correlation](./05-Identity-Correlation.md) -> [Pivoting](./06-Information-Pivoting.md) -> [Validation](./07-Validation.md).

## Rule
لا تجمع عنوان، هاتف، credentials، أو أي Sensitive Information. اشتغل على persona fictional ودوّن سبب كل pivot.
